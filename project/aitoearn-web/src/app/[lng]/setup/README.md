# 分步引导页

路由 `/[lng]/setup`。对应 `docs/rebuild/contract-runtime-config.md` 第四节 4.2：
进站做一次就绪检查，有必需项没通过就在顶部说清楚坏的是哪个功能，并且能在这里当场配好。

起因：线上「让 AI 提炼方向」一直报错，根因是上游 AI 从来没配过，
但这件事在网页上**完全看不出来**——用户只看到一句 Internal server error。

## 目录结构

| 目录/文件                       | 说明                                                                     |
| ------------------------------- | ------------------------------------------------------------------------ |
| `page.tsx`                      | 路由入口与 SEO 元数据。                                                  |
| `SetupPageContent.tsx`          | 页面外壳、步骤编排、展开/折叠、跳过与全局复检。                          |
| `setup.constants.ts`            | 每个检查项对应哪个服务、能不能就地填、改完要不要重启。                   |
| `setup.utils.ts`                | 纯函数：按键路径读写配置、受保护键判定、错误码到文案、排序与计数。       |
| `components/SetupStep/`         | 一步：说明三件事 + 就地填 + 保存 + 复检 + 必要时重启。                   |
| `components/ReadinessBanner/`   | 顶部横幅。挂在 `[lng]/layout.tsx` 的 `MainContent` 的 `banner` 位。       |

接口封装在 `src/api/system/`，状态在 `src/store/readiness.ts`。

## 为什么横幅的组件放在这里

它只服务于就绪检查这一件事，和引导页共用同一份文案（`setup` 命名空间）和同一个 store。
放进 `src/components/` 会让两边的文案和判定逻辑分家，迟早对不上。
挂载点在 `[lng]/layout.tsx`，那里只多一行 `banner={<ReadinessBanner />}`。

## 几条不能改掉的行为

- **说人话。** 横幅上是「AI 提炼方向现在用不了：上游 AI 还没配」，不是「配置缺失」。
  这个功能坏了很久没人报，就是因为页面上只写了一句 Internal server error。
- **未登录不拉，拉不到不说。** 接口要登录；拉不到结果时横幅不显示，宁可少提醒一次，
  也不要把所有人拦在一条自己都不确定的警告后面。
- **同一次会话只自动拉一次。** 复检是用户主动点的，走 store 的 `refresh()`，全局共用一份结果。
- **密钥不回填。** 配置里存的是明文，但输入框永远从空开始，只显示「已经设置过了」；
  留空提交 = 不改。整个目录里没有一处 console 打配置对象或表单值。
- **受保护的键不给填。** `assets`、`projects` 这些只能从 `.env` 改（契约 3.3），
  覆盖层会拒。渲染成输入框只会让用户填完收到一句保存失败。
  受保护名单以服务端返回的 `protectedPaths` 为准，本地那份只是兜底。
- **保存完必须复检。** 保存成功不等于配好了：地址填错、Key 过期都是保存成功但探测失败。
- **改完要不要重启，得说。** 只有 `agent` 一段热生效（契约 3.5），其余保存完复检还是红的；
  不说清楚，用户会以为自己填错了，然后反复改同一个框。
- **跳过只对非必需项开放，而且只在本页有效。** 跳过的是「这次不配」，不是「这项不需要」。

## 保存走的是哪套接口

就是 `/config` 那套覆盖层接口，没有另起一套（契约 4.2）。
`src/api/config-editor/` 归配置管理页维护，这里只调用、不改它，
需要放宽返回类型时在 `src/api/system/runtime-config.api.ts` 里包一层。

**整份提交，差异由服务端算**（契约 3.4）。网页自己算 diff 会把用户没动过的字段
冻结成覆盖值，以后改 `.env` 就改不动了。
